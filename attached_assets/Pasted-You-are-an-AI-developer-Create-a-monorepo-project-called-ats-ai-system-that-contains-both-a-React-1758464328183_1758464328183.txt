⚙️ Dependencies:
Frontend: react, react-router-dom, axios
Backend: express, mongoose, cors, nodemailer, axios

🎯 Features to Implement:
1. Role-based auth → Recruiters & Candidates
2. Recruiters can post jobs
3. Candidates can upload resumes
4. Backend extracts skills (basic regex placeholder)
5. Job matching → store vectors in array now (later Pinecone/Weaviate)
6. AI test generation → placeholder API returning dummy questions
7. Email notification → Nodemailer placeholder
8. Results dashboard for recruiters

🚀 MVP Flow:
Recruiter posts job → candidate applies → backend "matches" resume → dummy test generated → test submitted → recruiter sees result.
